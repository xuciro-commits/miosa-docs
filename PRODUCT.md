# MIOSA Docs reconstruction

## Platform

web

## Stack

SvelteKit, Svelte 5 and MDsveX, following the preceding investigation and the user's request to reconstruct its architecture. Node adapter; local content; no database required.

## Users

The owner wants to study the reference and replace its content with their own. Readers need clear documentation, examples and practice.

## Product Purpose

A complete, runnable homepage, documentation and pricing project with faithful visual/interaction language and maintainable source. Priorities confirmed by the user: visual fidelity and reuse.

## Capabilities and Constraints

Marketing homepage, interactive docs entrance and product field, workload/budget pricing, responsive documentation shell, editable MDsveX articles, synchronized examples, search, OpenAPI explorer, glossary, quizzes, local learning progress and practice labs. Public reference only. No MIOSA login, real credits or production account operations. AI service configuration stays on the server; a local document finder works without a service.

## Brand Commitments

Follow https://miosa.ai/, /docs and /pricing; use the captured CSS and computed tokens for each surface. Documentation follows /docs/learn/earn: restrained monochrome, floating navigation, pale canvas, white reading surface, small green reward badges and Geist typography. This is a local learning reconstruction, not an official MIOSA service.

## Evidence on Hand

Craft Anything browser captures of homepage, docs landing, pricing, earn, learn, glossary and tutorial pages; public CSS and computed-style contracts; preceding public bundle/source investigation. Private backend source and credentials are unavailable.

## Product Principles

One content registry drives navigation and discovery. Keep reading independent of optional services. Make every visible action work. Preserve honest local progress and configuration states.
