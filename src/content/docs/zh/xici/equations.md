## 五阶主方程

### 生成公理

```text
Omega_0 --SSB--> M(D_+, D_-) --projection--> X_t
constraint: phi(D_+) - phi(D_-) != 0
```

太极破缺生成由共轭算子张成的法则流形，并在时空截面投影为具象实例。极性差分为零则方程退化为静态。

### 演化与涌现

```text
X_(t+1) = Phi(X_t) = D_-( D_+(X_t) ) + xi_t
E = lim Phi^N(X_0) not in Span_linear(X_0)
```

系统在开合跃迁中连续迭代；多体非线性耦合产生不可被线性约简的高阶复杂态。

### 世界模型同构

```text
W_theta : X --Image--> z --Configuration--> S_t --Fluxion--> d --Dictum--> pi(a | S_t)
constraint: W_theta ~= M
```

面对不可约简的复杂表象，认知主体构建含几何潜空间、上下文张量、微观偏导与策略向量的世界模型，实现与客观流形的同构准入。

### 压缩与奇点

```text
theta* = argmin_theta { |theta|_MDL + KL( P_M(X) || P_W(X) ) }
t_ji = inf { t : lambda_max( dPhi/dX_t ) > 0 }
```

通过极小化描述长度剥离表象噪声，获得零偏推理基态；同时监控雅可比矩阵的最大特征值，在分岔前夕锁定临界时刻。

### 主动推理与对齐

```text
theta_(t+1) = theta_t - eta * grad F(X_(t+1), W_theta(S_t, a_t)) + J_negentropy
lim F(theta_t, a*) = F_min(M)  =>  action along geodesic
```

智能体在临界时刻实施前馈干预，以自由能梯度反向修正内部参数，并持续注入负熵与对抗自检；当模型与宇宙生成流形收敛，行动落在测地线上。

这五个方程不是装饰。第一个给出本体论前提，第二个给出演化机制，第三个给出表征条件，第四个给出预测上界，第五个给出控制律。任何一环被推翻，整套重构都要重写——这正是它值得被检验的原因。
