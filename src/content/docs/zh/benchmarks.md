## 方法和再现

- **独立且开源**：基准测试代码、运行器和每个结果文件都是公开的。 ComputeSDK 声明赞助商不能影响结果。 [github.com/computesdk/benchmarks](https://github.com/computesdk/benchmarks)
- **每个提供商使用相同的代码**：针对每个提供商使用相同的开放代码，具有固定的工作负载和固定的评分上限。每个指标报告最小值、最大值、中值、p95 和 p99，突发 TTI 还报告综合分数，同时奖励速度和可靠性。
- **自动化**：在命名空间运行器上的 GitHub Actions 上运行执行，并且每个结果都以 JSON 形式提交到存储库。存储库列出的时间表为每日太平洋时间下午 5 点、世界标准时间 00:00。实际上，突发 TTI 历史记录是在 2026 年 7 月 13 日期间每天进行一次，然后在周五每周进行一次，并在 2026 年 9 月 10 日和 2026 年 9 月 16 日进行额外运行。
- **实时排行榜和方法**：实时排行榜和完整的方法由 ComputeSDK 发布。 [computesdk.com/benchmarks](https://www.computesdk.com/benchmarks)

```bash
git clone https://github.com/computesdk/benchmarks
cd benchmarks

# MIOSA's burst TTI row, latest run
jq '.results[] | select(.provider=="miosa")' results/burst_tti/2026-10-23.json

# Every provider, sorted by median
jq -r '.results[] | "\(.summary.ttiMs.median)\t\(.provider)"' results/burst_tti/2026-10-23.json | sort -n
```

- [突发 TTI 结果](https://github.com/computesdk/benchmarks/tree/main/results/burst_tti)：每个带日期的突发交互时间结果文件。
- [DAX 结果](https://github.com/computesdk/benchmarks/tree/main/results/sandbox-dax)：每个过时的 DAX 沙箱构建结果文件。
