# 交互覆盖与边界

下表依据公开页面、发布的 JS/CSS 和私有浏览器观察重建。自动化覆盖在 `tests/priority-pages.spec.ts` 与 `tests/workflows.spec.ts`。它是已观察场景的清单，不是对不可见后端状态的承诺。

| 区域       | 实现的状态 / 操作                                                            | 验证                                             |
| ---------- | ---------------------------------------------------------------------------- | ------------------------------------------------ |
| 营销首页   | 线框、指针、滚轮、跳转、CLI 复制、页脚状态重试                               | 页面、移动端、状态失败/恢复                      |
| 文档入场   | 首访、回访、强制重播、暂停/恢复、跳过、入场飞行、飞行中 Esc                  | 自动化；焦点约束和恢复                           |
| 动态效果   | 减少动态效果；页面隐藏或卸载时停止；WebGL 不可用显示静态格网                 | 减少动态效果自动化；其余实现检查                 |
| 卡片       | 自动切换、悬停/焦点暂停、左右键/Home/End、指针拖动、取消、点击打开           | 键盘、首尾、拖动不误跳转自动化                   |
| 安装       | CLI/SDK、安装方式、语言、键盘选择、复制成功/拒绝                             | 切换与复制拒绝自动化                             |
| Logo 场景  | 自动轮换、选择、再次打开、拖动、抛掷、边界/碰撞、取消、Zap、减少动态效果     | 拖动、Zap、实际指南跳转自动化                    |
| 定价工作量 | 产品、规格、会话数量/时长、并发、CPU、使用量、方案最低额                     | 默认 `$45.39` 与极值自动化                       |
| 定价预算   | 预算、任务预设、可负担数量、容量限制、完整排名                               | 模式/预设/滑块/排名自动化                        |
| 不可用价格 | 未列出规格不转换为零；超方案容量单独提示                                     | 自动化                                           |
| 产品切换   | Apps/Databases 使用工作量模式；返回机器产品保留预算选择                      | 模式切换自动化                                   |
| 定价说明   | 独立 FAQ、来源、计价方法                                                     | 自动化                                           |
| 账户操作   | Free 注册；付费套餐保留 plan 参数；转官方站点                                | 链接意图自动化；未执行注册和付款                 |
| 搜索       | 快捷键、筛选、方向键/Home/End/PageUp/PageDown、Tab 切筛选、Enter、新标签打开 | 导航、失败仅请求一次、手动重试、Esc 先清空后关闭 |
| 文档壳     | 筛选、分组、主题、侧栏宽度、移动抽屉、目录与阅读进度、复制/Markdown          | 页面遍历、主题持久化、手机无横溢、复制自动化     |
| 文章       | MDsveX、共享语言、参数化示例、图表及缩放、学习指南                           | 示例与参数自动化；图表人工检查                   |
| 学习       | 分类、术语、练习、测验、重复提交与保存、七个实验、未开放视频                 | 测验幂等、刷新保存、七实验完整路径自动化         |
| API        | explorer、创建/查询/删除资源、无资源与无效 ID                                | 完整生命周期自动化；进程内存边界                 |
| OSA        | 无配置本地段落、来源、请求失败/重试、可选 SSE 上游                           | 本地来源自动化；真实模型未配置、未声称验证       |
| 错误路径   | 内容 404、接口错误、搜索加载失败、剪贴板拒绝、状态失败                       | 页面/搜索/复制/状态自动化                        |

定价原站也有旧版估算器代码留在发布 bundle 中；当前公开页面实际使用的比较器是本项目的复刻对象。没有把所有历史代码都变成新的产品选项。
